# rubik-cube

Learn group theory through interactive 3D cubing.

- Simulate a fully functional 3D Rubik's Cube with smooth rotations and drag-to-twist controls
- Implement optimal solve algorithms to calculate and display step-by-step solutions for any scrambled state
- Visualize group theory concepts by showing move permutations, cycle notation, and inverse sequences
- Track move history and statistics like time, move count, and scramble complexity
